# CO2 Emission Prediction: Multi-Model Comparison

Code for the paper **[Systematic overestimation and feature dependency in data-driven CO₂ emission prediction]**.

## Setup

```bash
pip install -r requirements.txt
```

Dependencies: scikit-learn, XGBoost, LightGBM, CatBoost, scikit-elm, pandas, numpy.

## Data

Place the raw dataset at `data/raw/merged_data.csv`. The dataset covers Chinese provinces/cities with climate, socioeconomic, energy, and CO₂ target variables.

## Usage

```bash
# Step 1: Split data (spatial & temporal)
python preprocess.py

# Step 2: Train all models
python main.py
```

Results are saved to `data/predict/{scale}_{method}_{k}/{model_name}/`.

## Configuration

Edit `config.py` to change experiment settings (data split, feature selection method, number of features, CV folds, etc.). To enable/disable models, edit the `MODELS` dict in `src/models.py`.

## Models

Linear, KNN, SVR, MLP, ELM, Random Forest, GBDT, AdaBoost, XGBoost, LightGBM, CatBoost, and more — each tuned via 5-fold grid search.

## Repository Structure

```
├── data/raw/          # Place merged_data.csv here
├── data/processed/    # Generated by preprocess.py
├── src/               # Data, features, models, training, evaluation, uncertainty
├── config.py
├── preprocess.py
└── main.py
```
